Одностраничный симулятор госзакупок (44-ФЗ / 223-ФЗ) + Android-приложение.

**Текущая версия: v1.5.1**

### v1.5.1 — мобильная адаптация

- Компактный интерфейс под экран смартфона: шапка, ресурс-чипы, вкладки, карточки, модалки, торги

## 📱 Android APK

Готовый файл: **[`Goszakupki-ULTIMATE-v1.5.1.apk`](Goszakupki-ULTIMATE-v1.5.1.apk)**

- WebView-обёртка: JS, звук, модалки и localStorage-сейвы работают как в браузере
- Экспорт сейва — прямо в «Загрузки» устройства, импорт — через системный выбор файла
- Кнопка «Назад» сначала закрывает окна игры
- Подпись: release-keystore (пароль `zakupki2026`, alias `zakupki`) — **нужен для установки обновлений, сохраните!**

### Сборка APK самостоятельно

```bash
cd android
# нужен JDK 17 + Android SDK (compileSdk 34)
gradle assembleRelease
# результат: app/build/outputs/apk/release/app-release.apk
```

## 📂 Структура

```
index.html                  # Госзакупки: игра (для браузера и GitHub Pages)

android/                    # исходники Android-обёртки (WebView)
  app/src/main/assets/index.html  # копия игры внутри APK
  keystore/release.keystore       # ключ подписи
bankir/                     # 🏦 Банкир (второй симулятор)
  index.html                # игра Банкир v1.4
  Bankir-v1.4.apk           # готовый Android APK
  android/                  # его WebView-обёртка (тот же keystore)
```

# 🏦 Банкир v1.4 — Симулятор

Управление банком: кредиты, вклады, БКИ, СБ, детектор лжи, должники, карьера.
[`bankir/index.html`](bankir/index.html) — работает офлайн без сервера.

### v1.4 — исправления и улучшения

| # | Исправление |
|---|---|
| 1 | NPL-процент считается по текущему портфелю (должники/все), а не по пожизненному счётчику — длинные партии больше не убивают игру неизбежным game over |
| 2 | «Корпоративное обучение»: −10 энергии действительно на день, как и обещано подписью (было — навсегда) |
| 3 | Повторный клик «Завершить день» не старит кредиты и не начисляет проценты дважды |
| 4 | Двойной тап больше не одобряет/не отклоняет случайно следующего клиента (350 мс дебаунс) |
| 5 | Репутация зажата в границы 0–100 |
| 6 | Загрузка mid-day сейва восстанавливает карточку текущего клиента |
| 7 | Метки слотов сохранения отображаются при старте; повреждённый сейв не роняет игру |
| 8 | После game over действия заблокированы, повторный вызов game over идемпотентен |
| 9 | Гонка «запрос документов» (500 мс) — результат больше не применяется к чужому клиенту |
| 10 | Экранирование HTML в логе/очереди/должниках (защита от импорта вредоносного сейва) |
| 11 | Формат чисел явно `ru-RU`; юрлицам показан балл БКИ |
| 12 | Компактный CSS для экранов ≤600 px |

### Что добавлено

- **Экспорт/Импорт сейвов** — JSON-файл в «Загрузки» (в APK через системный мост NativeSave), импорт с валидацией
- **Продолжение автосохранения** при запуске, если оно найдено
- WebView: отключён автоскейлинг текста (шрифты на телефоне не раздуваются)
