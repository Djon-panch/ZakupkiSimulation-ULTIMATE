## 📱 Android APK

Готовый файл: **[`Goszakupki-ULTIMATE-v1.5.1.apk`](Goszakupki-ULTIMATE-v1.5.1.apk)**

- WebView-обёртка: JS, звук, модалки и localStorage-сейвы работают как в браузере
- Экспорт сейва — прямо в «Загрузки» устройства, импорт — через системный выбор файла
- Кнопка «Назад» сначала закрывает окна игры
- Подпись: release-keystore (пароль `zakupki2026`, alias `zakupki`) — **нужен для установки обновлений, сохраните!**

### Сборка APK самостоятельно

```bash
cd android
# нужен JDK 17 + Android SDK (compileSdk 34)
gradle assembleRelease
# результат: app/build/outputs/apk/release/app-release.apk
```

## 📂 Структура

```
index.html                  # игра (для браузера и для GitHub Pages)
Goszakupki-ULTIMATE-v1.5.1.apk # готовый Android APK
android/                    # исходники Android-обёртки (WebView)
  app/src/main/assets/index.html  # копия игры внутри APK
  keystore/release.keystore       # ключ подписи
```
